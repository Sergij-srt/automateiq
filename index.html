Frequently Answered Questions

How do you ensure our company data remains secure and private?

Security is paramount. We advocate for self-hosted instances of n8n on your own dedicated cloud infrastructure (AWS, DigitalOcean, Hetzner) or on-premise Docker cluster. We never store client credentials on third-party SaaS servers, enforce strict environment variable encryption, and ensure full compliance with GDPR and enterprise data residency regulations.

Who pays for the OpenAI / Claude API usage?

You maintain 100% ownership of your Anthropic Claude 5 Opus and OpenAI API keys. Because we optimize prompt token length, enforce strict deterministic JSON schemas, and implement intelligent cache layers, monthly LLM costs for business workflows typically remain under $10 to $25 even for high-volume enterprise operations.

What happens if a third-party API (like HubSpot or Simpro) goes down?

Unlike fragile no-code setups, our pipelines implement exponential backoff retry queues, Redis deduplication locks, and dead-letter logs. If a third-party API rate-limits or returns a 5xx error, execution pauses, retries intelligently, and immediately alerts your designated Slack or Telegram engineering channel with full payload telemetry.

Do we get full ownership of the code and workflows?

Yes, 100%. You receive complete access and ownership of all n8n workflow definitions, Python scripts, database schemas, and documentation. There is zero vendor lock-in; your team can run, clone, or export the pipelines independently forever.

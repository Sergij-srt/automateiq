Frequently Asked Questions

Clear Answers on Security, Cost & Deployment

How do you ensure our company data remains secure and private?

Security is paramount. We advocate for self-hosted instances of n8n on your own dedicated cloud server (AWS, DigitalOcean, Hetzner) or Docker container. We never store client credentials on third-party servers, use environment variables for API secrets, and ensure full compliance with GDPR/data residency standards.

Who pays for the OpenAI / Claude API usage?

You provide your own API keys for Anthropic or OpenAI. Because we optimize prompt token length, leverage structured JSON outputs, and implement intelligent caching, typical monthly LLM costs for business workflows are negligible—often under $10 to $25 per month even for high-volume pipelines.

What happens if a third-party API (like HubSpot or Simpro) goes down?

Unlike fragile no-code setups, our pipelines implement retry queues with exponential backoff and dead-letter logs. If a third-party API returns an error or is unreachable, the execution pauses, retries intelligently, and immediately pings your designated Slack or Telegram channel with full error context.

Do we get full ownership of the code and workflows?

Yes, 100%. You receive complete access to the n8n workflows, Python scripts, database schemas, and documentation. There is zero proprietary agency lock-in; your team can modify, clone, or export the pipelines anytime.
